# Roadmap

TiddaLab AR Series is an early open-source WebAR starter collection. The roadmap focuses on making the project easier to run, easier to teach, and easier to extend.

## Near term

- Add screenshots for `basic.html` and `minimal.html`.
- Add a short demo video or GIF for the starter flow.
- Add browser troubleshooting notes for iOS Safari and Android Chrome.
- Add a simple custom marker tutorial from image to `targets.mind`.
- Publish a `v0.1.0` release once the documentation is complete.

## Example expansion

- Image target with static image overlay.
- Image target with transparent video overlay.
- Image target with 3D model overlay.
- Multiple image targets in one scene.
- Workshop-ready starter with placeholder assets and comments.

## Maintenance

- Keep examples aligned with current MindAR and A-Frame versions.
- Track browser compatibility issues.
- Add issue templates for bug reports and example requests.
- Document any dependency or CDN changes in release notes.

## Community

- Add bilingual English/Chinese documentation.
- Collect beginner questions into a troubleshooting guide.
- Invite contributions for classroom, workshop, and creative coding use cases.
