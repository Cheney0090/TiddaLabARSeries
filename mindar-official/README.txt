Strict Official MindAR Starters
--------------------------------
This folder contains two html files that match the official docs exactly:

1) minimal.html  -> 'Build the page' / 'Minimal' examples
   - Put 'targets.mind' next to this file and open via a local server.

2) basic.html    -> 'Basic' example using the hosted demo card.mind/card.png/softmind model.

To run (Windows):
  - double-click start-windows.bat then go to http://localhost:8080

To run (Mac):
  - double-click start-mac.command then go to http://localhost:8080
